# Code of Conduct

Be direct and be kind. Review the work, not the person. Assume the other side is trying to make the tool better.

Unacceptable: harassment, personal attacks, publishing others' private information, and sustained disruption of discussion. Maintainers may edit, remove, or reject contributions and comments that cross those lines, and may block repeat offenders.

Report problems to the maintainer through a GitHub issue or, if that is not appropriate, a direct message on GitHub.
